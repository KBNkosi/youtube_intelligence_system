# Research

This directory contains verified research findings relevant to the
YouTube Intelligence System.

Research should be organised by question/domain rather than by date.

## Rules

1. Research must answer a specific project question.
2. Findings must distinguish confirmed, conditional and unknown information.
3. Important findings must record their source.
4. Research should result in a decision or update to project knowledge.
5. Do not create duplicate research documents when an existing document
   covers the same subject.

## Planned Research Areas

- YouTube APIs
- YouTube Analytics
- Content Owner / CMS access
- Retention data
- Transcript access
- Existing solutions
- Relevant analytical approaches
